# PowerLink Technologies

Company website for PowerLink Technologies, Bangalore — UPS systems, inverter batteries, CCTV security and solar solutions. Serving customers since 2008.

## Tech stack

- Vite + React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- React Router
- Deployed on Cloudflare Workers (Wrangler)

## Development

```sh
npm install
npm run dev       # start dev server at http://localhost:8080
npm run build     # production build
npm run deploy:cf # build and deploy to Cloudflare
```
